# Esercizio: Problema Produttori/Consumatori con coda di messaggi asincrona

*Scrivere un’applicazione concorrente che implementi il problema dei Produttori/Consumatori singolo buffer utilizzando un protocollo di scambio di messaggi con invio asincrono. Il programma crei dei processi che agiscano da produttori e consumatori, utilizzando una coda di messaggi per produrre e consumare valori di tipo char[]. La sincronizzazione tra produttori e consumatori deve avvenire tramite l'utilizzo delle primitive di msgsnd() e msgrcv()*
